# Pigeon Pitch, One Line

Entry for [Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf) ($2): the one-line elevator pitch a city pigeon gives investors for its startup.

`main.ts` is a deterministic program (no randomness, clock, network, or input) that writes the pitch to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`):

> I'm raising a seed round — literally, seeds — for Coo, the Uber for breadcrumbs: 40,000 pigeons already queue on your statue daily, and my co-founder is the statue.

The joke: a seed round, taken literally by a pigeon, for an on-demand breadcrumb startup whose co-founder is the statue the flock already queues on every day.

Run it with Node 22+: `node main.ts` (writes to `/output/entry.txt`).
